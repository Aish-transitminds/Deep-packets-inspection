How DPI Works

📡
Packet Capture
Intercepts raw network packets flowing through the interface in real-time.
⚡
Load Balancing
Distributes packet flows across multiple Flow Processors using efficient hashing (LB0, LB1).
🧠
L7 Inspection
Flow Processors reassemble streams and analyze payload signatures to identify applications.
🛡️
Action & Policy
Decides whether to forward, drop, or log the traffic based on dynamic rulesets.
